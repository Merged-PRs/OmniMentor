# Demo kit

A clean, repeatable recording of OmniMentor working in a real terminal.

| File | Purpose |
|---|---|
| `run-demo.ps1` | Copies the skill into a temp directory, seeds a learner profile, launches OpenCode |
| `seed-progress.md` | A profile with Rust mastery, two due reviews, and a weak Python-dicts row |
| `SCRIPT.md` | Shot list, exact prompts, voiceover lines, and retake rules |

See `README.md` for recording tools and settings.

## One command

```powershell
powershell -File demo/run-demo.ps1
```

Start the recorder before the 5-second countdown ends. Nothing in the real repository is modified.
